# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in pyweight, please report it via
[GitHub Security Advisories](https://github.com/AZX-PBC-OSS/pyweight/security/advisories/new).

Please **do not** open a public GitHub issue for security-related matters.

## Supported Versions

The latest minor release is the only supported version. Older versions will not
receive security patches.
